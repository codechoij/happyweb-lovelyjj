video (2).mp4 제작 안내
=========================

이 문서는 대화 히스토리를 모르는 사람이 봐도 video (2).mp4를 다시 만들 수 있도록 정리한 실행 설명입니다.


1. 최종 파이썬 파일
-------------------

사용할 파일:

    C:\Users\jiyun_choi\git\webTry\tools\video (2).py

생성되는 출력:

    C:\Users\jiyun_choi\git\webTry\assets\gift-videos\video (2).mp4


2. 필요한 입력 파일/폴더
-----------------------

아래 폴더와 그 안의 사진/영상 파일이 필요합니다.

    C:\Users\jiyun_choi\git\webTry\assets\gift-videos\for_videos\couple
    C:\Users\jiyun_choi\git\webTry\assets\gift-videos\for_videos\memories

video (2).py는 SOURCE_ROOT를 아래 경로로 사용합니다.

    C:\Users\jiyun_choi\git\webTry\assets\gift-videos\for_videos


3. 필요한 파이썬 패키지
-----------------------

파이썬에서 아래 패키지를 import할 수 있어야 합니다.

    Pillow
    imageio-ffmpeg

설치가 필요하면 PowerShell에서 아래처럼 설치합니다.

    py -3 -m pip install pillow imageio-ffmpeg

프로젝트에 .video-deps 폴더가 있고 그 안에 패키지가 들어있으면, 스크립트가 자동으로 해당 폴더를 먼저 사용합니다.


4. 영상 생성 명령
-----------------

PowerShell을 열고 프로젝트 루트로 이동합니다.

    cd C:\Users\jiyun_choi\git\webTry

아래 명령으로 영상을 생성합니다.

    py -3 ".\tools\video (2).py"

주의:

    이 명령은 assets\gift-videos\video (2).mp4를 덮어씁니다.


5. 미리보기 이미지 생성
-----------------------

video (2).py에는 미리보기 시트 생성 옵션이 있습니다.

    cd C:\Users\jiyun_choi\git\webTry
    py -3 ".\tools\video (2).py" --preview

생성되는 미리보기 파일:

    C:\Users\jiyun_choi\git\webTry\assets\gift-videos\_preview\video (2)-preview.jpg

미리보기만 만들고 실제 mp4는 만들지 않습니다.
